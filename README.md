# teach-me-back# TeachWall

TeachWall is a learning website for students.

Students can post doubts and get answers from other students.
Students can upvote helpful answers.
Teachers can verify correct answers.
Students can also use Teach Me Back to explain a topic and receive a score and feedback.

## Features

- Post a doubt
- View doubts
- Add an answer
- Upvote an answer
- Verify an answer
- Teach Me Back scoring
- Teacher Dashboard

## How to Run the Project

1. Open the project in VS Code.
2. Open Terminal.
3. Run `npm install`.
4. Run `node server.js`.
5. Open `index.html` in a browser.
